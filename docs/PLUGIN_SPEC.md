# iPad Harness 自研轻量插件开发规范与社区共建准入标准

版本：V1.0  
目标：完全对标 Windows 能力，实现 iPadOS 零内存泄漏、零 Jetsam 闪退。

---

## 1. 核心准入原则

1. **零常驻原则**：插件未在执行任务时，严禁挂载常驻定时器（setInterval）、长轮询或保留无用对象引用。
2. **内存硬红线**：
   - 单插件执行期内存峰值不得超过 **50MB**。
   - 严禁一次性读入超过 5MB 的大文件，必须使用流式分片处理。
3. **极简依赖树**：
   - 严禁引入庞大的原生 C++ Addon（无法在 iOS arm64 简单链接）。
   - 优先使用 Node 原生标准库（s, path, child_process, crypto）。
4. **生命周期规范**：
   - 必须实现 mount（轻量挂载）与 unmount（深度卸载与垃圾回收提示）。

---

## 2. 社区 PR 准入流程

1. Fork 本仓库并新建分支 eat/plugin-xxx。
2. 在 plugins/ 目录下创建新插件包。
3. 提供基础冒烟测试脚本，证明插件在 100 轮并发调用下无内存持续攀升。
4. 提交 Pull Request，经核心维护者审核验证后合并入库。
